## 📌 Project Description

Real-time rocket flight analysis on ESP32 with regression, glitch detection, and memory-optimized data processing.

## 🎯 Objective

The project analyzes 100,000 altitude readings from an ESP32-based rocket tracker and extracts important flight parameters in real time.

These include:

- Gravity
- Apogee time and height
- Parachute deployment time and height
- Terminal descent velocity
- Landing time
- Glitch detection
- Altitude at a given time

## ⚙️ Project Levels

- Level 0 – Basic bring-up
- Level 1 – Descent and landing
- Level 2 – Gravity and apogee
- Level 3 – Deployment and ALT
- Level 4 – Glitch handling
- Level 5 – Performance optimization and worst-case testing

## 🧮 Key Techniques

- Streaming data processing
- Quadratic regression for the coast phase
- Linear regression for the descent phase
- Glitch detection
- Block-wise processing
- Memory optimization
- ESP32 CPU-cycle optimization
